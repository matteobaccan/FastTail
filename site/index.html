Everything you need to read logs

FastTail began as a successor to BareTail and has grown into a full log workbench. Every feature works on files that are still being written.

Zero-lag streaming engine

Rows are read on demand through a block cache, and appends are indexed as they arrive. Rotation, truncation and rewrites are detected without locking the writer.

Multi-stream docking

Tabs, splits and floating windows. Each stream has its own Follow, filters, search and view mode. Save the whole layout as a named session.

Filters and highlight rules

Include and exclude terms (text, regex or boolean expressions), a minimum level, a global filter, context lines, and priority-ordered colour rules with sounds and notifications.

Structured logs

JSON, logfmt, Apache and syslog lines, CSV and TSV tables, and your own named log formats, shown in a column view. Filter on fields: status>=500.

Search, queries and statistics

Regex and multi-line search, a results pane, search across all open streams, a pipeline query language, field statistics, and grouping of lines into patterns.

Time-aware

Timestamps are detected automatically. Get a time-range filter, go to a time, a timeline histogram, Δt columns, a merged timeline of several streams, and marks on lines out of order.

Any source

Compressed files and archives, rotated files as one stream, folders, stdin, SSH, Docker, journald, syslog, TCP and UDP, OTLP, the Windows Event Log, and debug output.

Four views

Text with inline JSON trees, a live HEX dump with byte search, x86 disassembly of PE and ELF files, and rendered Markdown or HTML.

Integrations

A web view for a browser, an MCP server for AI assistants, plugins, external tools, remappable shortcuts, and links from stack traces to your editor.

A terminal interface too

The terminal interface, fasttail-tui, brings the same engine to SSH sessions and servers without a desktop. It has windows, menus, mouse support, filters, rules, bookmarks, the column view and search across all streams.

Print mode runs FastTail's filters in scripts, with no window at all.

# follow a log in the window
fasttail app.log

# every match of a pattern, as a folder group
fasttail --all "logs/**/*.log"

# a file with its rotations, oldest first
fasttail --rotations /var/log/syslog

# the terminal interface, over SSH
fasttail-tui ssh://ops@web1/var/log/nginx/error.log

# pipe a command in, like less
docker logs -f api 2>&1 | fasttail -

Download

Every release has installers and archives for each platform. Get them from the latest release.

Windows x86_64

A per-user .msi installer (no administrator rights needed) or a .zip with fasttail.exe and fasttail-tui.exe.

Linux x86_64 / ARM64

.deb, .rpm, AppImage or .tar.gz, plus a terminal-only archive for servers. Requires glibc 2.35 or later.

macOS

A universal .dmg for Apple Silicon and Intel, or a .tar.gz per architecture. The builds are unsigned: see the README for the first launch.

From source

Use stable Rust: cargo build --release. The README lists the prerequisites.
