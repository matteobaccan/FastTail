An ultra-fast, multi-stream log monitor and tail viewer for Windows, Linux and macOS, in a window or in the terminal. Open multi-gigabyte logs instantly, follow dozens of them at once, and go from "something is wrong" to the line that explains it. Free and open source, written in Rust.

A tour of the window

FastTail began as a successor to BareTail and has grown into a log workbench. Everything below works on files that are still being written, and every screenshot is the real application.

Search

See where things go wrong, at a glance

Every stream can show a timeline histogram of its lines over time, with errors in red, and an overview strip beside the scrollbar. Click either to jump there.

  • Kept searches: up to eight searches highlighted at once, each with its own colour, hit count and lane on the timeline.
  • Regex and multi-line search, a results pane, and Search all streams (Ctrl+Shift+F).
  • Highlight rules with colours, sounds and desktop notifications; Notepad++ filter files import as rules.
  • Bookmarks with notes, a bookmark report, hide lines by hand, collapse repeated lines.
Structured logs

JSON and logfmt as a table, filtered by field

JSON, logfmt, Apache, syslog, CSV / TSV and your own named log formats open in a column view: pick, move and pin columns, and keep scrolling sideways.

  • Field filter terms: status>=500, level=error|fatal, user~=bot.
  • Values with units: latency>=1.5s matches 1700ms too.
  • Filter expressions: (payment OR refund) AND timeout NOT retry, plus a global filter over every stream and saved presets.
Statistics

Numbers, not just lines

Right-click a column and pick Statistics: the top values of a field, the share of each level, min · max · mean · p50 · p90 · p95 · p99 and a chart over time slices. Click a value to filter on it.

  • Query tab: where status>=500 | stats count(), p95(latency) by path | sort -count.
  • Plot a field over the timeline, Explain a spike (what changed in a time span), and an Operations view with a Gantt bar per request id.
Patterns

What kinds of lines does this log hold?

Ctrl+Shift+G groups thousands of lines into a handful of templates, with the parts that change shown as <*>. Each pattern has its count, its share, a sparkline of its volume, and where it was first and last seen.

The rare pattern that appears only in the incident window is usually the one you are looking for. Click it to show only those lines.

Time

Several logs, one timeline

A merged view interleaves several streams in the order of their timestamps, and keeps following them as they grow. A colour bar tells which file each line came from.

  • Timestamps are detected automatically: time-range filter (--since -15m), go to a time, a Δt column, UTC or local display.
  • Lines whose timestamp goes back are marked, counted and walked.
  • Split a big file by lines, size or time; export as text, CSV or HTML.
Keyboard

Every action one keystroke away

The command palette (Ctrl+Shift+P) lists every action and setting with its shortcut, greys out what does not apply and says why. Shortcuts can be remapped.

  • Tabs, splits and floating windows; save the layout as a named session.
  • Four views: text with inline JSON trees, a live HEX dump, x86 disassembly of PE / ELF files, rendered Markdown or HTML.
  • Five themes, sixteen languages, a PIN lock and a tray icon.

The same engine in the terminal

fasttail-tui (or fasttail --tui) brings FastTail to SSH sessions, containers and servers without a desktop. It is not a cut-down viewer: it has windows, menus, mouse support, splits, filters and rules, bookmarks, the column view, merged views and filter tabs, the analysis views, the command palette, remappable keys, five themes, and it shares the scratchpad with the window. It works in any terminal, including the Windows console, with --ascii borders for the old ones.

Five themes, in both interfaces

Pick a theme in Settings, or press Shift+T in the terminal to cycle through them (fasttail-tui --theme matrix from the command line). Every theme colours levels, search hits and kept searches in its own palette. In the terminal they use 24-bit colour where the terminal supports it, and fall back to 256 or 16 colours elsewhere.

Any source, not only files

Each source becomes a stream with the same filters, search, rules and views. The engine reads rows on demand through a block cache and indexes appends as they arrive; rotation, truncation and rewrites are detected without locking the writer.

Files and folders

Plain logs of any size and encoding, folders and patterns (logs/**/*.log) that open new files as they appear, rotated files (app.log.1, app.log.2.gz) as one stream.

Compressed and archives

.gz, .bz2, .xz, .zst, and entries of .zip, .7z and .tar archives, picked from a list.

Remote and containers

Files over SSH (ssh://ops@web1/var/log/app.log), Docker and Podman containers, Kubernetes pods (k8s://), journald.

Network

A TCP, UDP or syslog listener, and an OTLP/HTTP logs receiver for OpenTelemetry exporters.

Windows

Event Log channels and .evtx files, on this computer or another one (eventlog://host/channel), and debug output like DebugView.

Pipes and the clipboard

Standard input (command | fasttail -), the clipboard as a stream, and AUTOSAR DLT traces from automotive ECUs.

From the log to the work

FastTail connects the line you are looking at to the rest of your tools.

Your editor

Paths and file:line in stack traces open in VS Code, a JetBrains IDE, Sublime Text or any editor at that line, and a log message jumps to the logging statement that printed it.

AI assistants

An MCP server lets Claude and other assistants read what FastTail shows: the open streams, their visible lines, searches, bookmarks and filters.

A browser

A read-only web page of the open streams, served by FastTail itself on 127.0.0.1 behind a token, off by default.

Tickets and chat

Copy as excerpt puts the selected lines with their file, line numbers and time span in a Markdown, Jira or Slack code block.

Plugins and tools

Source plugins (any program whose output becomes a stream) and log format bundles; external tools run on a row, from a shortcut or when a rule matches.

Scripts

Print mode runs the filters without a window and writes text, JSON, logfmt, CSV or templated records.

The command line

One binary for the window, the terminal interface, print mode and the MCP server. Files open at a line (app.log:1204), filters and time ranges can be given up front, and print mode makes FastTail a grep that knows about log levels, timestamps and fields.

--filter / --exclude --filter-expr --since / --until --level --line --all --rotations --listen --print --output json --session --mcp 
# follow a log in the window, from line 1204
fasttail app.log:1204

# every match of a pattern, as a folder group
fasttail --all "logs/**/*.log"

# a file with its rotations, oldest first
fasttail --rotations /var/log/syslog

# the terminal interface, over SSH
fasttail-tui ssh://ops@web1/var/log/nginx/error.log

# the last 15 minutes of errors, as JSON, through jq
fasttail --print --since -15m --level error \
  --output json app.json | jq .fields.status

# pipe a command in, like less
docker logs -f api 2>&1 | fasttail -

Download

Every release has installers and archives for each platform. Get them from the latest release.

Windows x86_64

A per-user .msi installer (no administrator rights needed) or a .zip with fasttail.exe and fasttail-tui.exe.

Linux x86_64 / ARM64

.deb, .rpm, AppImage or .tar.gz, plus a terminal-only archive for servers. Requires glibc 2.35 or later.

macOS

A universal .dmg for Apple Silicon and Intel, or a .tar.gz per architecture. The builds are unsigned: see the README for the first launch.

From source

Use Rust 1.100 or newer: cargo build --release, or --no-default-features --features tui for the terminal only. The README lists the prerequisites.
